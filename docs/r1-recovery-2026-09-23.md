# R1 锁定恢复增量验证 — 2026-09-23

本轮修复 Regions 的 Contract 锁定回执不确定性。原实现先持久化 `PREPARING` lease，再调用 `lock`，却在失败回执后删除 lease；Contract 已持久化锁但回执丢失时，这会遗失唯一的 operation id。开赛随后中止时，若锁确实未生效，也可能把 lease 改成只重试退款的 `REFUNDING`，从此无法完成恢复。

现在任何未确认的 lock 结果均保留 `PREPARING` lease。撤销开赛或重启恢复先用原 operation id 请求退款：已有锁可直接退款；Contract 明确返回 `LOCK_CONFLICT`（无本 operation 的锁）时，才重放同一 lock 并退款。首次 lease 落盘失败时，在调用 Contract 前撤销内存记录。提供方不可用、合同不合格或结果仍不确定时保留 lease，阻止同场地新资金局；不能通过删除 `reward-funding.yml` 解锁。
